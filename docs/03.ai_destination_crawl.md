# Kế hoạch tổng hợp danh sách các destination

1. Các destinations sẽ có flag mặc định published = false, nếu flag này bằng false thì không hiển thị trên web
2. Cơ chế crawl data

   - Thêm 1 field source cho bảng destinations (json, array các url có dùng để tham khảo)
   - Khi generate các địa điểm hãy thêm các url trên
   - Không cần generate các destination_translations

3. Cho tôi 1 prompt template để đem lên gemini web yêu cầu nó tổng hợp danh sách các destination, output là json

4. Viết 1 script để xử lý data generate từ ai

## Prompt Template

```text
Analyze your knowledge base to compile a comprehensive list of significant tourist destinations in Vietnam. Do not limit the quantity; aim for maximum coverage of notable scenic spots, historical sites, and cultural attractions suitable for tourism.

For `source_urls`, strictly provide direct links to detailed articles, official pages, or wiki pages dedicated specifically to that destination. Do NOT use general "Top 10" listicles, aggregation pages, or homepage URLs.
url must be accessible publically

Output strictly in JSON format:
[
  {
    "slug": "unique-kebab-case-slug",
    "region": "north" | "central" | "south",
    "province": "Province Name",
    "category": "nature" | "culture" | "city" | "food" | "adventure",
    "moodTags": ["tag1", "tag2"],
    "source_urls": ["url1", "url2"]
  }
]
No markdown formatting, just raw JSON.
```
